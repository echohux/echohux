## 关于我 · About Me

我是一名 **AI 产品经理**，关注如何把真实用户问题转化为可运行的产品方案。从需求发现、工作流设计，到评测、Bad Case 分析与持续迭代，我希望让 AI 产品不仅能“做出来”，也能被验证和改进。

I'm an **AI Product Manager** focused on turning real user problems into working products—from requirement discovery and workflow design to evaluation, bad-case analysis, and iteration.

我也使用 **Vibe Coding** 快速构建和验证 MVP。代码是实现手段，产品判断、评测方法和学习闭环才是核心。

I also use **Vibe Coding** to prototype quickly. Code is a means; product decisions, evaluation methods, and learning loops are the real work.

## 我的工作方式 · How I Build

**发现问题 → 定义问题 → 快速原型 → 评测 → 问题归因 → 持续迭代**

*Discover → Define → Prototype → Evaluate → Analyze → Iterate*

- **产品 Product：** 用户研究、需求分析、PRD、工作流、指标与实验设计
- **AI：** Agent、RAG、工具调用、Prompt 与模型评测
- **落地 Execution：** 使用 Claude Code 与 Codex 快速构建和验证 MVP
- **质量 Quality：** 评测集、问题分类与闭环迭代
