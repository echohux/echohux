## Hi, I'm Xinyue 👋

I'm an **AI Product Manager** pursuing a master's degree at Shanghai University. I turn real user problems into working MVPs — from requirement discovery and workflow design to evaluation, bad-case analysis and iteration.

I use vibe coding to validate product ideas quickly. The code is a means; the product decisions, evaluation framework and learning loop are the work.

## How I build


discover → define → prototype → evaluate → analyze bad cases → iterate

- **AI:** agents, RAG, tool calling, prompt design and model evaluation
- **Execution:** rapid prototyping with Claude and Codex; shipping web MVPs independently
- **Quality:** evaluation sets, failure taxonomy and closed-loop iteration
